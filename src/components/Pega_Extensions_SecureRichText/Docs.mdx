# Support

This component is available out of the box in Pega 26.1 and will be **removed** from the Constellation UI Gallery in the next release. The out-of-the-box Rich Text editor can disable features such as inserting links and images.

# Overview

The Secure Rich Text editor is using the same presentational RTE component used in the Constellation application but the ability to insert URLs and images from the toolbar has been removed.
This component can be used if you want to prevent users to insert any url or images into the HTML and prevent XSS attacks.

Other features include:

- Set the toolbarMode to 'normal' to show headers, indentation and to 'basic' to only show lists and links
- Set showWordCounter to true and maxWords to enforce a maximum number of words in the RTE.
